# تنبيهات والتطبيق مغلق (Web Push) — خطة التنفيذ (لم تُنفَّذ: تحتاج خادماً ومفاتيح)

## لماذا لا يكفي ما عندنا
التنبيهات الحالية تعمل داخل التطبيق فقط (Toast + `Notification` والصفحة مفتوحة). المتصفح لا يشغّل JavaScript والتبويب مغلق، فلا توجد طريقة
محلية بحتة. Notification Triggers (جدولة محلية) غير مدعومة بالمتصفحات.

## ما يلزم فعلاً
1. **مفاتيح VAPID** (زوج: عام + خاص). العام يوضع بالتطبيق، **الخاص سر يُخزَّن في Supabase Secrets فقط** وليس بالملفات.
2. **جدول `push_subscriptions`** (SQL جديد): `code` (كود المزامنة) + `endpoint` + `keys` + `created_at`. يحتاج سياسات RLS مدروسة
   (نفس مشكلة `spaces`: الكتابة عبر دالة RPC).
3. **Edge Function مجدولة** (`pg_cron` أو Supabase Scheduled Functions) تعمل كل 15 دقيقة: تقرأ مهام/امتحانات المستخدمين من `spaces`
   (لذلك تعتمد على بنية البيانات الحالية)، وتحسب ما يستحق تنبيهاً، وترسل Push عبر مكتبة `web-push`.
4. **في التطبيق:** طلب إذن الإشعارات، `registration.pushManager.subscribe(...)` وإرسال الاشتراك لدالة RPC، وتعديل `sw.js` بمعالج `push`
   (موجود بالفعل معالج `notificationclick`).
5. **iOS:** يعمل فقط إذا ثُبّت التطبيق على الشاشة الرئيسية (PWA) وiOS 16.4+.

## قرارات تحتاج موافقتك قبل البدء
- استخدام Supabase Edge Functions + إضافة جدول جديد (تغيير بقاعدة البيانات).
- كلفة/حصة الخطة المجانية للدوال المجدولة.
- الخصوصية: الخادم سيقرأ مهامك وامتحاناتك ليحسب التنبيهات (حالياً كل شيء محلي).
- بدائل أبسط: تصدير `.ics` (متوفر) فتتولى تطبيقات التقويم بهاتفك التنبيه — وهي تعمل والتطبيق مغلق بدون أي خادم.
